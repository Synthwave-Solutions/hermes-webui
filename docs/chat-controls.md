# Conversation controls

Choose Chat or Super agent above the conversation. The choice uses the existing
session chat_mode contract: normal or super. A selection before chat creation
is staged for the new session; an existing conversation persists through the
session mode endpoint. Session navigation cannot apply a late mode reply to a
different conversation.

The microphone dictates text into the draft. The waveform opens Voice mode,
with mute, push-to-talk and speech interruption. Provider setup and billing stay
in administrator documentation; the conversation control uses a neutral label.
Connections use a plug icon and My approvals uses a shield with a check mark.

Open **Connectors** beside the message field to see which accounts you have
connected and which ones the agent may use in this conversation. Use **Connect**
or **Reconnect** for account authorization. Use **On in chat** or **Off in chat**
for the current conversation. Your choice applies from the next turn, survives
a reload and is personal to you in a shared chat. Turning a connector off keeps
the account linked. The chat mode, allowed tools and provider approvals still apply.

Filter **Connectors** by **MCP**, **CLI** or **API**, or search across the full list.
One integration can support multiple interfaces. Profile entries show their source
and configuration status. A local CLI installation or a configured endpoint alone
does not establish account sign-in. Use the account controls for personal connections.
