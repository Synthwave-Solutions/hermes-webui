# Conversation controls

Choose Chat or Super agent above the conversation. The choice uses the existing
session chat_mode contract: normal or super. A selection before chat creation
is staged for the new session; an existing conversation persists through the
session mode endpoint. Session navigation cannot apply a late mode reply to a
different conversation.

The microphone dictates text into the draft. The waveform opens Voice mode,
with mute, push-to-talk and speech interruption. Provider setup and billing stay
in administrator documentation; the conversation control uses a neutral label.
Connections use a plug icon and My approvals uses a shield with a check mark.
