# Product name

The product is **SynthPulse**. The page title, PWA manifest, default assistant
label, localized interface copy, exports, sharing page and voice instructions
use this spelling.

Saved default names `Hermes`, `SynPulse` and their `Control` variants resolve to
SynthPulse when displayed. Custom bot names and named profiles keep their own
identity. This does not rewrite stored chats or profile configuration.

Existing JavaScript exports, events, storage keys, environment variables and
legacy generated-title recognition retain their identifiers for compatibility.
New user-facing copy must use SynthPulse.
